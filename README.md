# Wireless-Optical-Communication-Using-Morse-Enco
This project demonstrates a basic Li-Fi (Light Fidelity) communication system using an LED and an LDR (Light Dependent Resistor). Instead of radio waves like Wi-Fi, this system uses visible light to transmit data wirelessly.


Components required : 

--- ARDUINO NANO 
--- LDR (Light Dependent Resistor)
--- LED
--- 100 OHMS AND 10K RESISTORS
--- OLED DISPLAY
--- BREAD BOARD AND JUMPER WIRES
